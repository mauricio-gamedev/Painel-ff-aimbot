# Project scope

## Product
FF Companion is an Android-first companion dashboard for Free Fire players.

## Supported features
- Local sensitivity profiles (Balanced, Rush, Sniper, Custom).
- Normal launcher shortcut for Free Fire / Free Fire MAX when installed.
- Shortcuts to supported Android display, battery, and app-info settings.
- Manual device-performance checklist.
- Device and app version information.
- Dark black/crimson interface.

## Explicit non-goals
- Aimbot, aim automation, recoil automation, or gameplay automation.
- DLL/SO injection, process hooks, memory editing, game-file modification, or overlays over the game.
- Anti-cheat bypass, anti-ban, ban evasion, or guaranteed account protection.
- Root commands, Shizuku operations, accessibility automation, or hidden services.
- Automatic RAM cleaning or force-stopping third-party applications.

## Privacy model
- No Internet permission.
- No account or credential fields.
- User profiles are persisted in app-private SharedPreferences.
- The only package visibility declarations are the two Free Fire package IDs used by the launch shortcut.
